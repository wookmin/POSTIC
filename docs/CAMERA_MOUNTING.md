# Notifyi 카메라 장착

## 현재 권장 방향

카메라는 로봇과 함께 실험하는 단일 입력 장치로 사용한다. 다만 카메라를 몸통이 크게 굽는 링크에 직접 고정하면 사용자의 자세 변화와 카메라 시점 변화가 섞인다.

현재 우선순위:

1. 로봇 상단 카메라로 실제 제품 동작 확인
2. 카메라 시야와 짐벌 보정의 영향을 로그로 측정
3. 필요할 때만 고정 마스트 또는 측면 카메라로 비교

## 장착 체크리스트

- 사용자의 얼굴·양쪽 어깨·상체가 한 프레임에 들어오는가
- 정상 자세에서 머리 여백이 충분한가
- 나쁜 자세 포즈에서도 얼굴이 프레임 밖으로 나가지 않는가
- 카메라 케이블이 목 관절과 브라켓에 걸리지 않는가
- 카메라 무게가 목 모터에 과도한 모멘트를 만들지 않는가
- 브라켓 유격과 진동이 없는가
- 렌즈가 모터나 프레임을 향하지 않는가

## 짐벌 보정

탑재 카메라를 사용할 때 config/posture.yaml의 camera_gimbal.enabled를 사용한다. 노트북 웹캠에는 no-camera-gimbal을 사용한다.

현재 보정은 몸통 pitch 변화에 맞춰 neck_pitch을 반대 방향으로 보정하는 1축 규칙이다. 영상의 yaw, roll, 거리 변화까지 보정하지 않는다.

## 장착 검증 순서

1. 카메라를 장착하고 전원을 끈 상태에서 수동 간섭을 확인한다.
2. 모터 없이 프레임을 보며 정상·나쁜 자세의 시야를 확인한다.
3. 짐벌 없이 low-risk 포즈를 dry-run으로 확인한다.
4. 짐벌을 켜고 같은 영상을 비교한다.
5. 프레임 이탈과 unknown 증가 여부를 로그로 비교한다.
6. 마지막에만 실제 모터로 짧게 시험한다.
