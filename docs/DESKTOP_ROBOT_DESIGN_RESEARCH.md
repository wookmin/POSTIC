# 탁상용 로봇 공학·디자인 설계 조사

조사 기준: 2026-10-02

## 1. 설계 결론

탁상용 로봇은 모터 수가 많은 것만으로 매력적인 제품이 되지 않는다. 반복 사용에서 사용자가 이해할 수 있는 표현, 방해받지 않는 타이밍, 안전한 회복, 수리 가능한 기구가 함께 설계되어야 한다.

Notifyi의 설계 방향은 다음 네 가지를 동시에 만족하는 쪽이 적합하다.

1. 형태는 복잡한 휴머노이드보다 단순한 데스크톱 오브젝트에 가깝게 유지
2. 움직임은 고정 포즈가 아니라 파라미터와 keyframe으로 제작
3. 센서·동작·표정·로그를 모듈로 분리
4. 사용자 집중도를 고려해 개입 가능성이 낮은 순간을 피함

## 2. 기구 설계 원칙

### 2.1 자유도는 표현 목적별로 배분

SPRITE는 6자유도 Stewart platform을 사용하지만, 자유도 자체를 기능으로 설명하지 않고 expressive movement와 affective communication을 설계 목표로 둔다.

따라서 새 모터를 추가할 때는 먼저 다음 질문에 답해야 한다.

- 이 축은 사용자가 구분할 수 있는 표현을 만드는가?
- 다른 축과 함께 움직일 때 새로운 의미가 생기는가?
- 이 축이 고장나도 로봇이 안전하게 정지할 수 있는가?
- 케이블·브라켓·하중 때문에 유지보수가 어려워지지 않는가?

### 2.2 모듈식 구조와 수리성

SPRITE는 상용 부품과 3D 프린트 부품, 교체 가능한 외형을 사용해 수리·복제·업그레이드를 고려했다. 제품 사례에서도 Eilik의 소품·자석 손처럼 외형과 상호작용을 교체하는 방식이 캐릭터 확장을 만든다.

적용 후보:

- 모터 모듈과 외장 모듈을 분리
- 카메라·디스플레이·브라켓을 교체 가능한 부품으로 설계
- 배선 커넥터에 서비스 루프와 strain relief 확보
- 하판을 열지 않고 주요 모터와 퓨즈에 접근
- 외장 스킨과 기구 안전 커버를 별도 부품으로 제작

### 2.3 중심 안정성과 탁상 경계

EMO와 Vector 같은 이동형 데스크톱 로봇은 낙하·충돌·탁상 경계 인식이 핵심 기능이다. 상체가 움직이는 고정형 로봇도 무게중심 이동과 전복 모멘트를 고려해야 한다.

설계 검증:

- 모든 표현 포즈에서 무게중심 투영점이 지지면 안에 있는가
- 카메라와 배터리의 위치가 모터 하중을 과도하게 키우지 않는가
- 모터 전원 차단 후 로봇이 갑자기 무너지지 않는가
- 케이블이 회전축과 외장 사이에 끼지 않는가
- 사용자가 책상을 치거나 로봇을 만졌을 때 안정적인가

### 2.4 비상 정지와 전원

SPRITE 연구에서는 모터 전원만 빠르게 끊는 비상 정지와, USB 기반 제어 컴퓨터는 계속 살아 있는 구조를 사용한다.

Notifyi에도 다음을 분리하는 설계가 필요하다.

- 소프트웨어 safe stop
- 모터 토크 해제
- 모터 전원 차단
- 상위 컴퓨터 전원
- 로그 flush와 사후 원인 기록

## 3. 표현 동작 설계

### 3.1 포즈보다 궤적

SPRITE는 keyframe과 Bezier 보간으로 happy dance 같은 동작을 만든다. 자유축 구조에서는 최종 포즈보다 진입·유지·이탈이 사용자의 인상을 크게 좌우할 수 있다.

따라서 동작을 다음 구간으로 정의한다.

~~~text
approach → emphasis → hold → recovery
~~~

각 구간에 다음 파라미터를 둔다.

- 목표 자세
- 이동 시간
- 속도 곡선
- 정지 시간
- 반복 횟수
- 회복 방식

### 3.2 움직임의 의미는 속도와 pause에도 있음

Expressive Robot Motion Timing 연구는 같은 경로라도 속도·타이밍을 바꾸면 사람이 로봇의 자신감, 자연스러움, 물체의 무게 같은 상태를 다르게 해석할 수 있음을 보였다.

따라서 Notifyi 동작 라이브러리는 관절 위치만 저장하지 말고 다음도 저장해야 한다.

- fast / slow
- abrupt / smooth
- decisive / hesitant
- long pause / short pause
- symmetric / asymmetric

### 3.3 표현의 명확성과 모호성

Cozmo 감정 표현 연구는 사용자가 로봇의 표정과 행동을 설계자의 의도와 다르게 해석할 수 있음을 보였다. 이것은 캐릭터 상호작용에는 장점이지만, 자세 피드백에는 위험할 수 있다.

자세 교정 동작은 다음을 지켜야 한다.

- 나쁜 자세 감지와 연결된 동작은 의미를 명확하게 유지
- 감정 표현과 안전 경고 표현을 시각·동작·색상으로 분리
- 사용자가 동작의 이유를 추측하지 않아도 되게 함
- 불쾌감이나 놀람을 유발할 수 있는 급격한 움직임을 제한

## 4. 개입 타이밍과 반복 사용

### 4.1 사용자의 interruptibility

Interruptibility-aware Robot Behavior 연구는 로봇이 사용자의 작업 중단 가능성을 고려하면 개입 타이밍과 로봇에 대한 사회적 평가가 좋아질 수 있음을 보였다.

Notifyi에서 직접 사용할 수 있는 저비용 신호:

- 사용자가 키보드·마우스를 빠르게 사용하는 중인지
- 얼굴이 카메라를 보고 있는지
- 최근 자세 회복에 성공했는지
- 직전 개입을 무시했는지
- 개입 빈도가 최근에 급격히 증가했는지

### 4.2 인지 부하에 따른 표현 채널

최근 proactivity 연구에서는 높은 인지 부하 상황에서 음성보다 비언어적 단서가 더 적합할 수 있다는 결과가 보고됐다.

Notifyi의 현재 모터 피드백에도 같은 원칙을 적용할 수 있다.

- 사용자가 바쁠 때: 작고 조용한 동작
- 사용자가 유휴 상태일 때: 더 명확한 포즈
- 직전 피드백을 무시했을 때: 즉시 더 큰 동작으로 escalation하지 않음
- 반복될 때: cooldown과 suppression을 우선 적용

### 4.3 새로움과 습관화

반복 상호작용 연구는 첫 경험의 novelty가 시간이 지나며 줄어들고, 이후에는 예측 가능성·실용성·일관성이 더 중요해질 수 있음을 보여준다.

따라서 동작 다양화는 매번 무작위로 바꾸는 것이 아니라 다음 순서가 적합하다.

1. 초반: 로봇의 의미를 학습시키는 일관된 동작
2. 중기: 제한된 motion primitive를 순환
3. 장기: 사용자의 반응에 따라 빈도·강도·표현 채널 조정

## 5. 사용자 경험과 제품 디자인

### 5.1 위협적이지 않은 형태

SPRITE 연구는 친근하고 비위협적이며 외형을 커스터마이즈할 수 있는 탁상형 디자인을 목표로 했다. Vyo 연구는 제품형 오브젝트와 사회적 행위자 사이의 균형, 비방해성, 안심감을 설계 목표로 삼았다.

Notifyi 디자인 후보:

- 날카로운 노출 링크보다 둥근 외장
- 움직이는 관절을 부분적으로 가리는 안전 커버
- 카메라 렌즈를 감시 장치처럼 보이지 않게 배치하되 동작 상태 LED는 명확하게 표시
- 사용자의 시야를 가리지 않는 낮은 높이
- 전면에 모든 센서를 모으지 않고 시선·카메라·표정의 역할을 구분

### 5.2 카메라의 신뢰감

제품 사례에서 카메라·마이크·클라우드 사용은 사용자 신뢰의 핵심 요소다. Vector는 카메라·음성 상태 표시와 온보드 처리 범위를 문서화한다. QTrobot은 엣지 AI와 깊이 카메라를 연구 플랫폼의 구성 요소로 제시한다.

필수 디자인 요소:

- 카메라 활성 상태 표시
- 영상 저장 여부의 명확한 설명
- 로컬 처리와 외부 전송의 분리
- 실험 중 카메라 시야를 가릴 수 있는 물리적 셔터 또는 비활성화 방법

### 5.3 디스플레이는 표정이 아니라 상태 채널

화면을 추가하더라도 모든 정보를 얼굴 표정으로만 전달하지 않는다.

- 파란색: 관측 중
- 노란색: 개입 대기
- 주황색: 로봇이 움직이는 중
- 빨간색: 안전 정지
- 짧은 표정: 감정·캐릭터 표현

상태와 감정의 의미를 색상과 애니메이션에서 분리하면 사용자가 로봇의 안전 상태를 오해할 가능성이 줄어든다.

## 6. Notifyi에 적용할 설계 원칙

### 즉시 적용 후보

- fixed pose를 keyframe motion primitive로 확장
- 모터 위치와 별도로 speed, pause, recovery를 저장
- robot profile과 capability를 분리
- 비상 정지에서 모터 전원과 상위 컴퓨터를 분리
- 카메라 활성 상태와 영상 저장 여부를 제품 외관에 표시
- 서비스 루프·교체 브라켓·안전 커버를 설계 기준에 포함

### 데이터가 쌓인 뒤 적용

- interruptibility 추정
- 개인별 cooldown 정책
- 반응에 따른 동작 강도 조정
- 표현 동작의 사용자 해석 평가
- 모터 궤적을 이용한 감정·의도 분류 실험

### 아직 보류

- LLM이 자유롭게 관절 움직임을 생성
- 사용자 자세를 모든 축에 1:1로 복사
- 매번 무작위로 움직임과 시간을 바꾸는 정책
- 안전 검증 전에 자유축을 모두 동시에 구동

## 7. 설계 검증 지표

공학 지표:

- 표현 포즈 도달 성공률
- 관절별 목표 오차
- safe stop 발생률
- 전류·온도·전압 여유
- 케이블 간섭·기구 충돌 횟수
- 모터 교체 시간

사용자 지표:

- 동작 의미 이해도
- 놀람·불쾌감
- 방해감
- 개입 후 자세 회복률
- 반복 세션에서의 무시율
- 로봇이 신뢰할 만하다고 느끼는 정도
