# Notifyi 실험 프로토콜

## 목적

3초 동안 지속된 나쁜 자세에 대한 고정 로봇 포즈가 사용자의 자세 회복과 이후 유지에 어떤 영향을 주는지 반복 측정한다.

## 고정 조건

- 개입 조건: posture_trigger
- 나쁜 자세 지속 기준: 3초
- 정상 회복 확정: good 1초
- 카메라 해상도: 640 x 480
- 자세 모델: 설정에 지정된 동일 모델
- 참가자 ID: P01과 같은 익명 코드
- 세션당 카메라 위치와 조명 기록

## 세션 전

1. 참가자에게 로봇이 자세를 판단하고 움직일 수 있음을 설명한다.
2. 로봇의 가동 범위와 비상 정지 방법을 설명한다.
3. 카메라가 얼굴과 상체를 볼 수 있도록 배치한다.
4. 스캔과 dry-run을 수행한다.
5. 세션 ID와 참가자 ID를 기록한다.

## 세션 중

참가자는 평소 작업을 수행한다. 실험자가 특정 자세를 의도적으로 오래 유지하게 할 때는 그 구간을 별도로 표시한다.

각 세션에서 기록할 것:

- 시작·종료 시각
- 카메라 배치
- 모터 구동 여부
- 자세 개입 횟수
- 관측 중단 횟수
- 안전 정지 여부
- 예외적인 참가자 반응

실험자는 자세를 임의로 정상 또는 나쁨으로 판정해 로그를 수정하지 않는다.

## 세션 후

~~~bash
python scripts/summarize_posture_logs.py \
  --input data/runs \
  --output-dir data/summaries
~~~

CSV를 확인하고 로그와 설문 응답을 익명 ID로 연결한다. 영상 원본이 필요하면 별도 동의와 보관 정책을 적용한다.

## 분석 제외 기준

- 카메라가 1초 이상 끊긴 세션 구간
- 모터 safe stop이 발생한 개입
- 개입 시작 전부터 사람이 프레임 밖에 있었던 경우
- 하드웨어 오류로 실제 포즈가 전달되지 않은 경우
- 설정 버전이 다른 세션을 무표시로 합친 경우
