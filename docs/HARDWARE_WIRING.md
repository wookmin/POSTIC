# Notifyi 하드웨어 연결

## 현재 구현 기준

현재 Python 프로그램은 Dynamixel SDK로 직렬 버스에 직접 연결한다. 따라서 현재 코드의 실제 실행 경로는 OpenCR ROS 2 통신이 아니라, 노트북 또는 상위 컴퓨터에 연결된 Dynamixel 직렬 어댑터를 기준으로 한다.

현재 설정:

- 포트: /dev/ttyUSB0
- Baudrate: 1000000
- Protocol: 2.0
- 모델: 2XL430-W250
- 전체 ID: 1부터 10
- 실제 구동 ID: 1, 4, 5, 8, 9

## 논리 연결

~~~text
상위 컴퓨터
  ├─ USB 카메라 또는 로봇 탑재 카메라
  └─ USB 직렬 어댑터
       └─ Dynamixel TTL 버스
            └─ ID 1 ... ID 10

별도 전원 공급
  └─ Dynamixel 버스
~~~

위 구조는 현재 코드가 기대하는 논리 구조다. 실제 배선에서 사용하는 어댑터, 전원공급기, OpenCR 연결 여부는 장비를 확인해 확정해야 한다.

## OpenCR을 사용할 때

OpenCR이 모터 버스의 전원·통신·저수준 제어를 담당하고, 상위 컴퓨터가 카메라·자세 인식·정책·로그를 담당하는 구조가 권장된다. 다만 현재 저장소에는 OpenCR과 Python 사이의 명시적인 통신 어댑터가 없다.

따라서 OpenCR을 연결했다고 해서 현재 src.main이 자동으로 OpenCR을 통해 모터를 제어하는 것은 아니다. 이 기능을 추가할 때는 Dynamixel packet을 직접 보내는 JointWriter와 별도의 OpenCR transport를 만들어야 한다.

## 전원과 배선 주의

- USB만으로 모터 전원을 공급하지 않는다.
- 전원 공급기와 모터 정격 전압·전류를 확인한다.
- 전원을 연결한 상태에서 신호선을 임의로 분리하지 않는다.
- 데이지체인 커넥터의 방향과 체결 상태를 확인한다.
- 모터가 기구적으로 걸린 상태에서 토크를 인가하지 않는다.
- 배터리와 모터 전원 분배는 실제 회로도와 부품 매뉴얼로 별도 검증한다.

## 배선 확정 전에 기록할 것

- 전원 공급기 모델과 출력
- 배터리 모델과 보호회로
- 직렬 어댑터 또는 OpenCR 포트
- 모터 버스의 실제 순서
- 카메라 전원과 USB 연결
- 비상 전원 차단 방법

이 문서에 사진과 실제 회로도를 추가하기 전에는 확정되지 않은 배선 정보를 팀 표준으로 사용하지 않는다.
