# Notifyi 실험 개인정보 원칙

## 기본 원칙

- 참가자 이름과 이메일을 로그에 저장하지 않는다.
- P01과 같은 익명 참가자 ID만 사용한다.
- 현재 프로그램은 원본 영상과 음성을 저장하지 않는다.
- 자세 proxy와 이벤트만 저장한다.
- 개인 장비 메모는 docs/private에 두고 공유하지 않는다.

## 로그 보관

실험 로그에는 카메라 경로와 세션 메타데이터가 포함될 수 있다. 장치 경로나 개인 폴더명이 외부에 노출되지 않는지 확인한 뒤 공유한다.

data/runs와 data/summaries는 Git에 커밋하지 않는다. 분석 결과를 공유할 때는 익명화된 CSV만 사용한다.

## 영상이 필요한 경우

원본 영상을 저장해야 한다면 별도 동의를 받고, 다음을 함께 기록한다.

- 저장 목적
- 보관 기간
- 접근 가능한 사람
- 삭제 방법
- 얼굴·화면·문서 등 부수적 개인정보 처리 방법

현재 프로토타입의 기본 분석에는 원본 영상보다 이벤트 로그를 우선한다.
