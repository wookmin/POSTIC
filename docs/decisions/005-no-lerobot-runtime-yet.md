# ADR 005: 현재는 LeRobot 런타임을 직접 도입하지 않음

## 결정

현재 Notifyi는 Python 기반 결정론적 자세 반응 루프를 유지하고, LeRobot은 데이터셋·하드웨어 추상화·학습 정책 참고로만 사용한다.

## 이유

- 현재 목표는 3초 고정 개입의 효과 측정이다.
- 학습 데이터와 하드웨어 인터페이스가 아직 안정되지 않았다.
- 학습 모델이 안전 게이트를 우회해서는 안 된다.

## 재검토 조건

반복 시연 데이터와 실제 출력 텔레메트리가 충분히 쌓이고, 학습 정책이 고정 정책보다 나은지 비교할 수 있을 때 검토한다.
