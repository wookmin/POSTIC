# legacy

2모터 시절 음성 제어 실험 코드. **현재 동작하지 않으며, 의도적으로 고치지 않았다.**

`voice_motor.py` 는 57600 bps / `MOTOR_IDS = [1, 2]` 를 그대로 갖고 있다.
버스는 1 Mbps 로 바뀌었으므로 지금 상태로는 통신이 되지 않아 무해하다.

baudrate 만 1 Mbps 로 고치면 오히려 위험해진다. ID 1, 2 는 여전히 존재하지만
재배열 이후 예전과 다른 물리 모터이고, 이 스크립트는 속도 제어 모드로 계속
회전시킨다. 음성 명령 한 번에 정체불명의 관절 두 개가 돌아간다.

되살릴 조건:
1. `config/joints.yaml` 에 관절-ID 매핑이 확정된 뒤
2. `config/robot.yaml` 에서 버스 설정을 읽도록 고치고
3. 대상 ID 를 명령행에서 명시적으로 받도록 바꾼 뒤

`voice_test.py` 는 vosk STT 단독 테스트로 모터를 건드리지 않는다. 그대로 동작한다.
